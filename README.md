# RAG Python Cookbook

A hands-on implementation of RAG systems built while working through O'Reilly's *RAG with Python Cookbook* by Dominik Polzer.

## About This Repository

This repo documents my learning journey and hands-on implementation of RAG concepts, organized by chapters in the book.

## Repository Structure

Each chapter folder contains its own README describing the concepts covered, code, and what was implemented.
```text
rag-python-cookbook
├── ch0_getting_started_with_rag
├── .gitignore             # Git ignore file
└── README.md              # Repository documentation
```

## Getting Started

### Prerequisites

- Python 3.10+
- An API key for [OpenAI / Anthropic / etc.]

### Installation

```bash
git clone https://github.com/<your-username>/rag-python-cookbook.git

# Create venv
python3 -m venv .venv

# Activate venv
. ./.venv/bin/activate
```
